#  Smart Route Finder

This project is a web-based application that calculates the shortest path between two points on a Leaflet.js map using Dijkstra’s algorithm and visualizes the path.

---

##  Project Objective

To find the shortest path between two user-selected points on the map using Dijkstra's algorithm and display it visually on the map.

---

##  Features

- Interactive map with Leaflet.js
- Start and end point selection by clicking markers
- Node and edge structure defined via `graph-data.json`
- Shortest path calculation using Dijkstra’s algorithm
- Path visualization on the map using polyline
- Total distance display to the user

---

## 🛠 Technologies Used

- HTML, CSS, JavaScript
- Leaflet.js
- Dijkstra algorithm (JavaScript implementation)
- JSON data structure (sample graph)
